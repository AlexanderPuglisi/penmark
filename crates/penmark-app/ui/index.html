Firma un file

Rendi tuo ciò che crei.

Trascina un file: PenMark registra il tuo nome, la data e un'impronta unica. Se qualcuno lo cambia anche di poco, si vede.

Trascina qui il tuo file
Qualsiasi formato: .blend, .png, .mp4, .glb, .wav, .pdf, codice. La firma va accanto, in un piccolo file .penmark.

Di chi è questo file?

Chiunque può controllare un file firmato. Non serve un account e non serve internet.

Trascina qui il file ricevuto
Va bene anche il suo .penmark: servono tutti e due nella stessa cartella.
Se il file è stato cambiato
«Firmato, ma modificato dopo la firma.» Si vede subito che non è più l'originale.
Se lo firma qualcun altro
«Firma vera, ma di una chiave che non conosci.» Il nome lo può scrivere chiunque: conta la chiave.
